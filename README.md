# Customer Segmentation & Sales Forecasting | Python

A data analysis project using RFM (Recency, Frequency, Monetary) analysis 
to segment customers by value, plus a simple sales forecasting model — 
built on a real-world retail transactions dataset.

## Overview 

Using the Online Retail Dataset (UCI) — 390K+ real transactions from an 
online retailer — this project answers a core business question: which 
customers matter most, and where is revenue heading next?

## What the project covers

- Data Cleaning: Handled missing Customer IDs, removed returns/cancelled 
  orders, and fixed invalid price entries
- RFM Analysis: Calculated Recency, Frequency, and Monetary metrics for 
  4,300+ customers
- Customer Segmentation: Scored and grouped customers into 7 actionable 
  segments — Champions, Loyal Customers, At Risk, Lost, New Customers, 
  Potential Loyalist, Needs Attention
- Data Visualization: Built charts to compare segment sizes, average 
  customer value, recency distribution, and frequency vs. monetary 
  relationships
- Sales Forecasting: Analyzed the monthly revenue trend and used Linear 
  Regression to forecast the next 3 months of sales

## Key Results

- Segmented 4,338 customers into 7 groups, identifying 962 "Champions" 
  (top-value customers) and 824 "Lost" customers requiring re-engagement
- Forecasted revenue growth for the next 3 months following the observed 
  upward trend:
  - Month +1: ~$1,037,000
  - Month +2: ~$1,089,000
  - Month +3: ~$1,141,000
